# Hamparo 

Aplicación Android desarrollada como Trabajo para la asignatura de Desarrollo de Interfaces (DAM), orientada al cuidado, seguimiento y asistencia de personas dependientes, facilitando la comunicación entre pacientes, cuidadores y familiares.

---

## 📱 Funcionalidades principales

- Gestión de pacientes, cuidadores y familiares.
- Registro de constantes vitales y evolución gráfica.
- Gestión de medicación y recordatorios.
- Sistema de alertas SOS.
- Historial médico y seguimiento clínico.
- Interfaz accesible y orientada a usuarios mayores.
